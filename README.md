# BlackCat
Use of Python in Geophysics

## Python Learning Resources

This repository contains comprehensive Python learning materials with simple, clear examples. Learn Python from basics to advanced concepts through practical code examples.

### 📚 Available Learning Files

1. **python_basics_tutorial.py** - Complete introduction to Python fundamentals
   - Variables and data types
   - Basic operations (math, strings)
   - Control structures (if/else)
   - Loops (for, while)
   - Data structures (lists, dictionaries)
   - Functions
   - String manipulation
   - List comprehensions
   - Error handling

2. **problem_solving_examples.py** - Real-world problem-solving practice
   - Find maximum in a list
   - Check prime numbers
   - Reverse strings
   - Count vowels
   - Fibonacci sequence
   - Factorial calculation
   - Remove duplicates
   - Palindrome checker
   - Sum of digits
   - Common elements finder
   - Temperature converter
   - Word frequency counter

3. **oop_examples.py** - Object-Oriented Programming concepts
   - Class definitions
   - Methods and attributes
   - Inheritance
   - Class vs instance variables
   - Special/magic methods
   - Practical examples (BankAccount, Student Management, etc.)

4. **file_handling_examples.py** - Working with files
   - Reading files
   - Writing files
   - Appending to files
   - Error handling with files
   - CSV-like data processing
   - File statistics
   - Copying files
   - Searching in files
   - File existence checks

### 🚀 How to Use

Each file is self-contained and can be run independently. Simply execute any file with Python:

```bash
python python_basics_tutorial.py
```

or

```bash
python problem_solving_examples.py
```

or

```bash
python oop_examples.py
```

or

```bash
python file_handling_examples.py
```

### 💡 Learning Path

**For Complete Beginners:**
1. Start with `python_basics_tutorial.py` to learn fundamentals
2. Practice with `problem_solving_examples.py` to apply what you learned
3. Move to `oop_examples.py` to understand object-oriented programming
4. Finally, explore `file_handling_examples.py` for file operations
